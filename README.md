One original line of plain text: the last words a phone says as its
battery hits 1 percent, written for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4).

## The line

> Good news: I'm finally dying. Bad news: so is your 6 a.m. alarm.

## How it works

`main.py` writes that single line to `/output/entry.txt` (64 characters,
UTF-8, no trailing newline).

```sh
python3 main.py
```
